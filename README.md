# 系统仿真打通链路的操作手册

> 目标：**一周内**跑出第一张 BER 曲线和净增益数字，作为后续器件设计的规格书。
> 所有命令都在 `sim/` 目录下执行。

---

## 0 · 先回答你的问题：顺序是什么

### 结论

```
系统仿真（Python 自建）  →  导出规格书  →  器件仿真（FDTD/模式求解）  →  版图  →  流片
   ↑ 你现在在这里，1~2 周              ↑ 拿到 specs 才允许开始，3~4 周
```

**不要先做器件仿真。** 三个硬理由：

1. **器件仿真的每个参数都是系统指标的函数。** 抽头数 `N_T`、延时 `Δt`、插损上限、调谐效率要求、动态范围——这些必须先由系统仿真算出来。没有规格书就画 MZI，你无法判断该画多宽、耦合区多长、插损上限多少。
2. **系统仿真里不需要器件物理模型。** 用的只是"传输矩阵 + 插损标量 + 带宽标量"这种**行为模型**。所以这一步完全不需要 Lumerical。
3. **时间成本差 1~2 个数量级。** 系统仿真一个配置 0.1 秒，一个 MZI 的 3D FDTD 收敛要几小时。用几小时去验证一个你还没确定要不要的规格，是纯浪费。

### 软件选择（明确结论）

| 阶段 | 用什么 | 为什么 |
|---|---|---|
| **打通链路** | **Python + numpy/scipy**（已给你搭好） | 可复现、可 Git、可跑 PSO、零 license、和后面训练是同一套代码 |
| 交叉验证（投稿前） | VPIphotonics 或 OptiSystem | 审稿人认商业软件；但要等结果稳定后再做，且只验证 STEP A 和 STEP C 两处 |
| 器件级 | Lumerical MODE + FDTD（或 Tidy3D / femwell） | 见第 7 节，**有明确入口条件** |

**别一上手就用 VPI。** 它的价值在"可信度背书"，不在"探索速度"。你现在需要的是快速试错，不是可信度。

## 4 · 四个验收关卡

**每过一关才能进下一关。** 这就是你和"跑完就完事"的区别。

### 关 1 · STEP A：模型对不对

**看什么**：四行"误差"必须都是 `0.00%` 或 `<2%`。

**它在验证什么**：你在 `simcore.py` 里搭的"复光场色散 → 平方律探测"链路，在小信号下必须精确复现你文档里的解析式

$$H(\omega)=\cos\!\left(\frac{\pi D\lambda^2 L f^2}{c}\right)$$

**为什么这关最重要**：这一步过了，说明"物理是对的"；后面所有 BER 数字才有意义。这一步不过，后面全是自欺欺人。

**不通过怎么办**：见第 6 节排查表。

### 关 2 · STEP B：图 1 是否合理

打开 `out/fig1_channel.png`。检查三件事：

- 每个距离的曲线都有周期性的**深凹陷**（谱零点），零点位置随距离增加而**向低频移动**（`f0 ∝ 1/√L`）
- 竖直虚线（信号带宽 22.5 GHz）与曲线的交点位置：20 km 时约 `-6.6 dB`
- 曲线在零点处下探到 −40 dB 以下（我用 `20log10(|H|+1e-4)` 处理零点）

**判定**：20 km 时首零点 13.55 GHz 落在信号带宽 22.5 GHz 内部 → 需要均衡。若首零点远高于信号带宽，这个场景就不值得做 OSP（这正是你文档第八节第 3 条判据）。

### 关 3 · STEP C：图 2 是否讲得通

打开 `out/fig2_ber.png`。这是你的**第一张结果图**。检查：

| 曲线 | 预期行为 | 若不符合说明什么 |
|---|---|---|
| BtB（蓝） | 最陡，最先穿过 2e-2 | 若不平滑 → 噪声模型或对齐有问题 |
| 无均衡（橙） | 很快走平，形成**误码地板** ~1.2e-1 | 若继续陡降 → 色散没加上 |
| FFE（绿） | 也走平 ~8.8e-2，只比无均衡好一点 | 若明显优于 OSP → 你的 OSP 没做好 |
| OSP（红） | 一路降下去，最终穿过 2e-2 | 若有地板 → OSP 带宽没覆盖够（见第 6 节） |

**关于 FFE 那条"几乎没用"的曲线——这是对的，不是 bug。**

大调制深度（`kappa=0.9`）下，`sqrt()` 非线性 + 色散使链路**本身就是非线性系统**，线性 FFE 无法反演，必然有误码地板。这正是你文档第三节那句"IIR+FIR 级联后整体等价于带递归的**二阶 Volterra** 非线性均衡器"的物理来源。OSP 在**光场**上做均衡，天然绕开了这个非线性。

这句话可以直接写进论文的 motivation。

### 关 4 · STEP D：图 3 是否出现 U 形

打开 `out/fig3_taps.png`。BER 必须**先降后升**：

```
N=1  BER=1.26e-01     ← 抽头不够
N=5  BER=3.63e-03
N=9  BER=1.86e-03     ← 最优（就是你文档说的"比理论值 N_T=5 多留几个余量"）
N=31 BER=8.09e-03     ← 插损 7.3 dB 把 SNR 吃掉了
```

同时插损曲线单调上升（4.0 → 7.3 dB）。**这就是你文档里"纯 FIR 抽头越多越好"这个陷阱的定量证明。** 拿这张图去组会，比讲十页公式有说服力。

## 5 · 换成你自己的场景

只改 `run_link.py` 顶部的 `CFG`：

```python
CFG = dict(
    Rs=25e9,          # ← 你的符号率（例：56e9 / 100e9）
    n_sps=8,          # 每符号采样点；Rs 提高时保持 ≥4
    beta=0.8,         # 升余弦滚降
    half_span=8,
    n_sym=2 ** 15,    # 符号数；要测 1e-4 以下请提到 2**17
    D=17.0,           # 你的光纤色散系数
    lam=1550e-9,      # 工作波长
    L_km=20.0,        # 传输距离 ← 最该扫的参数
    taps_per_symbol=2,# Δt = T/2
    wg_loss_dB_per_ps=0.0214,   # 3 dB/cm, ng=4.2
    coupling_dB=4.0,  # 2 × 2 dB 光栅耦合
    kappa=0.9,        # 调制深度
)
```

**建议做的第一批扫描**（每个 6 秒，一晚上能跑完）：

| 扫描变量 | 范围 | 你要提取的结论 |
|---|---|---|
| `L_km` | 5, 10, 20, 30, 40 | 净增益 vs 距离曲线 → 找到"值得做 OSP"的距离下限 |
| `Rs` | 25, 50, 75 GBd | 净增益 vs 速率 → 验证 B²DL 约束 |
| `lam` | 1310, 1550 nm | 波长依赖性（1310 nm 处 D≈0，色散小） |
| `coupling_dB` | 2, 4, 6, 8 | 插损敏感性 → 倒推对工艺的要求 |
| `wg_loss_dB_per_ps` | 0.01, 0.02, 0.05 | Si 波导损耗上限 → **这是器件设计的硬指标** |

最后两行就是你要交给器件仿真的**规格书**。

## 6 · 排查表（这些坑我都踩过）

| 现象 | 根因 | 处理 |
|---|---|---|
| 自检误差 20~35% | 探测单音频率没落在 FFT 栅格上 → 频谱泄漏 | `kb = round(fm*N/fs)`，用整数 bin |
| 自检误差 >100% | `D` 单位没换算到 `s/m²`（少乘 `1e-6`） | 检查 `fiber_H_intensity` |
| 所有 BER ≈ 0.5，EVM ≈ 100% | AGC 增益被 PAM4 直流偏置吃掉 | 判决前**先隔直** `z - mean(z)` |
| `sqrt` 出现 nan / 强度为负 | 升余弦过冲达 ±1.97×，`1+κu < 0` | 按最坏过冲归一化 + 加偏置，或降 `kappa` |
| 抽头越多越好，不触底 | 直接把解析 chirp 采样成抽头，带 ±5 dB 截断纹波 | **改用 LS 拟合**（`design="ls"`），9 抽头就能压到 0.999~1.001 |
| 抽头够多但 BER 有地板 | 拟合带宽只覆盖了强度带宽，未覆盖 `sqrt` 带来的频谱再生 | 拟合带宽取 **1.5 ×** 信号带宽 |
| 对齐总是错 | 用"方差最大"作判据 | 改用**已知训练符号的数据辅助 LS**（`align_downsample`） |
| BER 曲线抖动 | 测试比特数不够（1e-4 需 ~1e7 bit） | 提高 `n_sym`，或每条曲线跑 3~5 个随机种子取误差棒 |

**建议现在就做一次实验**：把 `design="ls"` 改成 `design="chirp"`，重跑 STEP D。你会看到"抽头越多反而越差"的假象——这就是为什么文献里最后都要用 PSO 微调抽头，而不是直接用解析解。这个对比本身就是论文里很好的一张图。

## 7 · 什么时候才准进器件仿真

### 入口条件（三条全部满足）

- [ ] STEP A 误差 < 2%
- [ ] STEP C 画出了 OSP 净增益为正的曲线
- [ ] **拿到了自己的规格书**：`N_T = ?`、`Δt = ?`、`插损上限 = ? dB`、`相移范围 ≥ ?π`、`带宽 ≥ ? GHz`

### 器件仿真用什么

| 任务 | 软件 | 输出 |
|---|---|---|
| 波导模式 / 有效折射率 / 群折射率 | Lumerical **MODE**（商业）或 **femwell**（开源） | `n_eff(λ)`、`n_g` → 换算延时线长度 `L = cΔt/n_g` |
| 直波导传播损耗 | FDTD 或 **截断法实测** | dB/cm → 回填 `wg_loss_dB_per_ps` |
| MMI / 定向耦合器 分束比 | **FDTD**（Lumerical / Tidy3D / MEEP） | S 参数 → 分束不均匀度 |
| MZI 传输谱、FSR、消光比 | FDTD 提 S 参数 → **INTERCONNECT** 级联 | 谱线 → 与系统仿真的理想模型对比 |
| 螺旋延时线 | MODE + FDTD（弯曲损耗、模式失配） | 单位长度延时、插损 |
| 相移器效率 / 热串扰 | **CHARGE + HEAT + MODE**（或 COMSOL） | `mW/π`、串扰矩阵 → 回填训练电流预算 |

### 器件仿真 → 系统仿真的接口

器件仿真的终点不是"图好看"，而是**一组 S 参数**。做法：

1. FDTD 得到单元器件的 `S(f)`（复数、宽带）
2. 导出为 `npz` 或 Touchstone `.s2p`
3. 在 `simcore.py` 里把理想抽头 `w` 换成"真实 S 参数级联后的等效抽头"
4. **判据：系统性能下降 < 1 dB**。若下降更多，说明器件规格不达标，回去改器件

这一步就是"从理想走向真实"的关口，也是你论文里"仿真 vs 实测"那张图的左半边。

## 8 · 下一步扩展（按优先级）

1. **加 PSO 训练**（1 天）：把 LS 抽头作为初值，用 PSO 在 BER 上微调。能直接对比 LS / PSO / Adam，这就是你文档第三节算法表的内容。
2. **加容差蒙特卡洛**（1 天）：给抽头相位加高斯误差模拟波导长度误差，画出"延时误差 vs BER"，直接回答你文档第七节问题 1。
3. **加 WDM 多波长**（3 天）：改 `lam` 数组，验证同一组权重跨波长复用 → 回答问题 2。
4. **加 VNLE 基线**（3 天）：二阶 Volterra，把 FFE 的 8.8e-2 地板补上，让对比更公平。
5. **接 VPI 交叉验证**（1 周）：只验证 STEP A 和 STEP C 两个数，不要重搭整条链路。

## 附 · 一句话总纲

> 系统仿真负责**回答"值不值得做、要做到什么规格"**；
> 器件仿真负责**回答"能不能做到这个规格"**。
>
> 顺序反了，你会花三个月画一个不知道用来干什么的 MZI。
